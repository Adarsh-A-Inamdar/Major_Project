IMPLEMENTATION
7.1 Installation Steps:
To ensure proper setup of the proposed leukemia classification and grading system, the following installation steps must be followed:
Step 1: Install Operating System and Dependencies
Ensure the system is running Windows 10/11 (64-bit) or Ubuntu 20.04+.
Update system drivers, especially GPU (CUDA-enabled) drivers for deep learning acceleration.

Step 2: Install Python Environment
Download and install Python 3.8 or higher from the official source.
Verify installation using:
python –version

Step 3: Create Virtual Environment
A virtual environment isolates project dependencies and prevents conflicts.
python -m venv leukemia_env
Activate it:
Windows: leukemia_env\Scripts\activate
Linux/Ubuntu: source leukemia_env/bin/activate

Step 4: Install Required Python Libraries
Install core frameworks and supporting libraries:
pip install numpy pandas matplotlib seaborn scikit-learn opencv-python tensorflow torch torchvision

Step 5: Install Metaheuristic Algorithm Libraries
Metaheuristic libraries such as DEAP and PyGMO are installed using:
pip install deap pygmo
If custom metaheuristic modules are used, place them in the project directory and import via Python scripts.

Step 6: Install Deep Learning and Image Processing Dependencies
For enhanced image analysis and training acceleration:
pip install pillow torchvision opencv-python-headless
If using GPU and TensorFlow, install CUDA-compatible builds (optional but recommended):
pip install tensorflow-gpu

Step 7: Install Database (optional)
If storing results or training logs:
MySQL
sudo apt install mysql-server
MongoDB
pip install pymongo

Step 8: Configure Jupyter Notebook or IDE
Install and launch Jupyter Notebook for experimentation:
pip install notebook
jupyter notebook
Alternatively, configure VS Code or PyCharm using a Python interpreter pointing to the virtual environment.

Step 9: Verify Installation
Run a sample test script:
import numpy as np
import sklearn
import tensorflow as tf
print("Setup Successful")
If no errors appear, the environment is successfully configured.


7.2 Psudo Code:Pu

1. Preprocessing & Input Handling
BEGIN
    User uploads blood smear image
    Read image
    Resize image to 224 × 224
    Convert image to RGB
    Normalize pixel values using ImageNet mean & std
    Convert image to tensor format
END

2. Metaheuristic Optimization (PSO) – Feature Selection (If included)
BEGIN PSO
    Initialize swarm of particles with random feature subsets
    FOR each particle DO
        Extract selected features
        Evaluate fitness using validation accuracy
    END FOR

    Update particle velocities and positions
    Repeat until convergence or max iterations reached

    Select best feature subset (global best)
END PSO

3. Multi-Task ResNet18 Model (Classification + Grading)
BEGIN MODEL
    Load pretrained ResNet18 backbone
    Remove final fully-connected layer

    Add Head-1: Linear layer → predicts Leukemia Type (ALL, AML, CLL, CML)
    Add Head-2: Linear layer → predicts Grade (Grade 1, Grade 2, Grade 3)

    Load trained weights (multitask_model.pth)
    Set model to evaluation mode
END MODEL

4. Forward Pass & Prediction
BEGIN PREDICTION
    Input preprocessed image to model

    (type_logits, grade_logits) = model(image)

    type_index = argmax(type_logits)
    grade_index = argmax(grade_logits)

    Map index → Leukemia Type:
        0 → ALL
        1 → AML
        2 → CLL
        3 → CML

    Map index → Grade:
        0 → Grade 1
        1 → Grade 2
        2 → Grade 3

    Return predicted class and predicted grade
END PREDICTION

5. Output Display (Frontend)
BEGIN UI
    Display uploaded image preview
    Show:
        "Predicted Leukemia Type: <CLASS>"
        "Predicted Disease Grade: <GRADE>"
END UI

PSEUDOCODE SUMMARY
1. User uploads blood smear image
2. Preprocess image: resize → normalize → convert to tensor
3. (Optional) Apply PSO to select optimal feature subset
4. Load multi-task ResNet18 model
5. Forward pass:
       type_logits, grade_logits = model(image)
6. Predict class = argmax(type_logits)
7. Predict grade = argmax(grade_logits)
8. Map predictions:
       Class → ALL/AML/CLL/CML
       Grade → Grade 1/Grade 2/Grade 3
9. Display results to user
